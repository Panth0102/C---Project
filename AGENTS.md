# Agents & Technical Documentation

## 1. Technology Stack

| Layer | Technology | Reasoning |
|-------|------------|-----------|
| Frontend | **React** + **TypeScript** (Vite) | Modern, type‑safe SPA; fast dev server; easy integration with Tailwind.
| UI Styling | **Tailwind CSS** | Utility‑first approach for precise vintage design; easy theming with custom color palette.
| Backend | **Python** + **FastAPI** | High‑performance async API; excellent OpenAPI generation; straightforward integration with PostgreSQL.
| Database | **PostgreSQL** | Relational, ACID‑compliant; supports complex queries for queue calculations.
| ORM | **SQLAlchemy** + **Alembic** | Declarative models + migrations; familiar to Python developers.
| Hosting (frontend) | **Vercel** | Optimized for static React builds, edge functions, automatic CI.
| Hosting (backend) | **Render** | Simple service deployment for FastAPI; supports PostgreSQL add‑on.
| CI / Testing | **Vitest** (frontend) & **pytest** (backend) | Modern testing frameworks, snapshot & coverage support.
| Version Control | **Git** (repo already present) | Standard source control.
| Documentation | **Markdown** in `docs/` | Human‑readable, version‑controlled spec files.

## 2. Design Rules (UI/UX)
- **Vintage Identity**: All components must use the defined color palette and typography (condensed serif headings, classic serif body). No default component libraries (e.g., Bootstrap) unless heavily customized.
- **Accessibility**: WCAG AA contrast; keyboard navigation; ARIA labels on interactive elements.
- **Responsiveness**: Mobile‑first breakpoints (≥640px, ≥768px, ≥1024px). Layouts must collapse gracefully, preserving vintage look.
- **Component Library**: Build reusable UI primitives (`Button`, `Card`, `Modal`, `Badge`) in `frontend/src/components/ui` with Tailwind custom classes for the palette.
- **Iconography**: Use custom SVGs for barbershop motifs (scissors, razor, pole). Avoid generic icon fonts.
- **State Indicators**: Use antique‑gold for active, burnt‑copper for warnings, muted‑cream for completed.

## 3. Architecture Rules
- **Separation of Concerns**: Frontend only consumes the public API; no server‑side rendering except Vercel edge functions for env config.
- **API Versioning**: All endpoints under `/api/v1/`.
- **Authentication**: Simple token‑based (JWT) for receptionist/barber/admin roles; customers are anonymous but identified by queue token.
- **Real‑time Updates**: Implement via WebSocket (`fastapi-websocket`) or long‑polling; fallback to periodic polling for simplicity.
- **Database Schema** (high‑level):
  - `users` (id, role, name, email, password_hash) – only for staff.
  - `services` (id, name, price, duration, description).
  - `barbers` (id, name, status).
  - `queues` (id, token, service_ids, barber_id, customer_name, contact, status, created_at, updated_at, position).
- **Business Logic Layer**: Service layer in `backend/app/services` handling token generation, assignment, ETA calculation.
- **Error Handling**: Consistent JSON error format (`{ "detail": "..." }`). Use FastAPI exception handlers.
- **Testing Strategy**: Unit tests for services, integration tests for API endpoints, UI component tests.

## 5. Development Instructions
1. **Setup Backend**:
   ```sh
   cd backend
   python -m venv venv
   source venv/bin/activate
   pip install -r requirements.txt
   alembic upgrade head
   uvicorn app.main:app --reload
   ```
2. **Setup Frontend**:
   ```sh
   cd frontend
   npm install
   npm run dev
   ```
3. **Run Tests**:
   - Backend: `pytest` in `backend/tests`.
   - Frontend: `npm run test` (Vitest).
4. **Local Development Workflow**:
   - Use feature branches per screen or service.
   - Commit linting with `pre-commit` (if configured).
   - Push to remote; Render and Vercel will auto‑deploy on main branch.
5. **Styling**:
   - Extend Tailwind config in `frontend/tailwind.config.ts` to add custom colors and fonts.
   - Add `src/styles/index.css` with paper‑grain background utilities.
6. **Localization**:
   - Store strings in JSON per language (`src/locales/en.json`, `src/locales/gu.json`).
   - Use a simple i18n hook (`useI18n`) to toggle.
