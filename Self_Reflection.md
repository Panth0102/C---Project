# Self Reflection

During the development of the Salon Queue Management System, I used **Kiro and Google Antigravity** as AI-assisted coding tools. Both tools helped me generate code, organize the project structure, and implement different application features.

One issue I encountered was that the AI agents did not consistently follow the intended vintage design theme. Some generated screens looked like modern SaaS dashboards, with generic layouts, rounded cards, and styling that did not match my original barbershop design inspiration.

I noticed this while comparing the generated interfaces with my reference design. Although the functionality was being implemented, the visual consistency across different screens was missing.

To fix this, I refined my prompts by providing more specific design instructions. I defined a consistent colour palette using deep olive, aged parchment, burnt copper, and antique gold. I also specified vintage typography, decorative borders, textured backgrounds, and explicitly instructed the agents to avoid generic modern dashboard designs. I added these requirements to the project documentation and `AGENTS.md` so that both Kiro and Antigravity could follow the same design guidelines.

This experience taught me that AI coding tools do not automatically understand the complete vision of a project. The quality of their output depends heavily on how clearly the requirements and constraints are communicated. Reviewing the generated code and refining prompts were essential parts of the development process.
